📄 RESUME LINE 1 — Word by Word
"Built a four-role platform for children, doctors, caregivers, and parents with real-time meltdown prediction, a clinical chatbot, gamified social-skills training, and virtual therapy, reducing caregiver response time from 4.3 minutes to <200ms via closed-loop emotion sensing."
four-role platform
One codebase, 4 separate React portals — /app (child), /caregiver, /parent, /doctor. Each has its own nav, shell, and pages. Role stored in SQLite after Firebase signup.
real-time meltdown prediction
Two things: (1) CNN detects current ASD state live. (2) LSTM predicts meltdown risk 12–24 hours ahead using historical emotion sequences. Not reactive — proactive.
clinical chatbot
Mitra — a companion chatbot for the child. Currently uses empathetic pre-written replies. Designed to plug into AWS Bedrock / Claude as the LLM backend.
gamified social-skills training
CalmQuest engine — 6 games built with Phaser 4: BullyBlock, EmotionPop, CalmControl, MyCalmSpace, PeerPressurePanic, SafeStrangerQuest. Each trains a specific ASD social skill.
virtual therapy
Doctor schedules a session → POST /api/therapy/sessions → parent accepts → GET /api/therapy/stream-token → Stream Video SDK JWT → WebRTC video call. All 4 roles can join.
4.3 min → <200ms
Before: caregiver manually watches child, notices distress, decides to act = avg 4.3 min. After: CNN detects state change → WebSocket pushes to caregiver dashboard → alert fires. All in <200ms.
closed-loop emotion sensing
"Closed-loop" = the system detects → decides → acts automatically without human in the loop. Webcam → CNN → WebSocket → UI adaptation (dim screen, change audio) → no manual step needed.
📄 RESUME LINE 2 — Word by Word
"Developed a CNN-based emotion system using MobileNetV2 + AffectNet to detect 8 emotions and map them to 4 ASD states, adapting UI, audio, and brightness in <38ms; a two-stage LSTM predicted meltdown risk 12–24 hours ahead at ∼0.78 AUC-ROC"
CNN-based emotion system
Convolutional Neural Network. Takes a 224×224 face image as input, runs it through convolutional layers that learn spatial features (edges, textures, shapes), outputs emotion probabilities.
MobileNetV2
Google's lightweight CNN architecture. Uses depthwise-separable convolutions — 8–9x fewer operations than standard CNN. Pretrained on ImageNet (1.2M images). We replaced the final layer with Linear(1280→4) for our 4 ASD classes. Runs in <20ms on CPU.
AffectNet
Largest facial expression dataset — 450K real-world images, 8 emotion classes: anger, contempt, disgust, fear, happy, neutral, sad, surprise. Collected from internet search queries. We used YOLO-format annotations.
8 emotions → 4 ASD states
Neutral + Surprise → Calm
Happy → Happy
Fear + Sad → Distressed
Anger + Contempt + Disgust → Overwhelmed
Mapping done in CLASS_MAP dict in train_mobilenet.py
adapting UI, audio, brightness
EmotionContext wraps the entire app. When state = Overloaded → CSS applies grayscale(30%) + opacity(90%). When Anxious → saturate(50%). Audio cues and screen brightness change. All driven by setEmotion() in React.
<38ms latency
Measured from frame received at WebSocket → JSON packet sent back. Breakdown: face detect ~10ms + MobileNetV2 forward pass ~15ms + numpy smoothing ~2ms + WebSocket overhead ~5ms = ~32ms total. Under 38ms.
two-stage LSTM
Stage 1 = CNN gives real-time state per frame (Calm/Distressed/etc). Stage 2 = LSTM takes a TIME SERIES of those states over hours → predicts binary meltdown risk for next 12–24 hours. LSTM = Long Short-Term Memory, handles sequential/temporal data.
meltdown risk 12–24 hours ahead
LSTM input = sequence of hourly aggregated emotion states. Output = probability score 0–1. Shown as "Risk Score" on doctor dashboard. Proactive — doctor/parent can intervene BEFORE meltdown happens.
∼0.78 AUC-ROC
Area Under ROC Curve. Measures how well the LSTM separates meltdown days from non-meltdown days. 0.5 = random guess. 1.0 = perfect. 0.78 = model correctly ranks a meltdown-risk day above a safe day 78% of the time. Solid for a medical-adjacent task.

TRAINING SETUP

  • Dataset: AffectNet YOLO format
  • Froze MobileNetV2 feature extractor
  • Only trained classifier head
  • Adam optimizer lr=0.001
  • CrossEntropyLoss
  • Max 2000 samples/class (balanced)
  • 3 epochs (fast local training)
  • Saved best_model.pth
  • Device: MPS (Mac) → CUDA → CPU

ASD-AWARE DESIGN

  • AffectNet = neurotypical faces
  • ASD kids have flat/atypical affect
  • Shannon entropy > 1.10 → flag
  • Top1-Top2 margin < 0.12 → flag
  • Flagged → 20% confidence discount
  • Flagged → log for clinician review
  • Graceful degradation → trust HRV/PPG
  • Personal baseline EMA α=0.05
